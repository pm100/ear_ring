# App Store announcement email

`app-store-announcement.html` is a paste-ready email: open it in a browser, select all, copy,
and paste into the compose window (Outlook / Apple Mail keep the image and link).

- Badge is hosted at `https://jollygoodsw.com/wp-content/uploads/2026/10/app-store-badge.png`
  (WordPress.com media library) — email clients need a public https URL.
- `app-store-badge.png` / `badge.svg` are the official Apple "Download on the App Store"
  black badge, unmodified (from Apple's badge service, `tools.applemediaservices.com`).
- App Store link: `https://apps.apple.com/us/app/earring-ear-trainer/id6802447554`
